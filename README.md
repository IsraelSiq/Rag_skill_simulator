# Rag Skill Simulator

Simulador de habilidades para Ragnarok Online — servidor **TRUEMMO**.

## Features
- Todas as classes: 1ª → 2ª → Trans → 3ª → 4ª
- Auto-complete de dependências de skills
- Clique esquerdo: +1 nível | Clique direito: -1 nível
- Tooltip com dependências e descrições
- Contador de pontos usados / disponíveis

## Stack
- React + Vite + TypeScript
- Tailwind CSS
- Zustand (state management)

## Dev
```bash
npm install
npm run dev
```
